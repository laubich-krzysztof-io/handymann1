# Surface: home page (/), Polish only, premium variant on branch `premium`

Mode: Persuade. Audience: owners of better guesthouses, 4-star hotels, aparthotels and investment apartments in the Karkonosze. Action: report a fault or ask about regular care. Proof: published net/gross rates, worked sample bill, SEP licence, the same person; nothing invented. User rejected the map world and the architectural-drawing world; pinned: premium, no graphics, no SVG illustrations or icons, existing content only.

## Direction contract
THESIS: Premium through typography, colour and pace alone, like the printed card of a good mountain hotel. Refuses icons, illustrations, badges and any decorative graphic.
OWN-WORLD: Petrol (sea-green) fields alternating with cool white and pale mint-grey stone; mint as the only accent (user asked for less luxurious colours and chose petrol over cobalt, green and rust). Brygada 1918 (a Polish serif from 1918) for headlines, prices and reading text; Albert Sans in small spaced capitals for labels, navigation and buttons. Square buttons, single hairline rules, CSS dots instead of check icons. Only raster: the real job photos. Logo mark kept as the brand.
STORY: The owner reads one large serif line on deep green, sees exact prices set like a menu, the process in four steps, and calls a number set at headline size.
FIRST VIEWPORT: Dark header flowing into a full-width pine field; the headline at display size across the left two thirds; lead and actions below it; the sample log entry as quiet text in the right column.
FORM: user-pinned direction (premium, typography only); seed: none (pinned by user)
SIGNATURE: the phone number in the contact section set at headline size in the serif.
